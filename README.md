# Backend - Entrega Final

## Docker Image
https://hub.docker.com/r/ry0xz/backend-final

## Requisitos
- Tener Docker Desktop instalado y corriendo.
- Tener un archivo `.env` en la raíz del proyecto con:
  - MONGO_URL
  - PORT (recomendado 8080)

## Run con Docker (usando imagen de Dockerhub)
1) Descargar imagen:
```bash
docker pull ry0xz/backend-final:latest
